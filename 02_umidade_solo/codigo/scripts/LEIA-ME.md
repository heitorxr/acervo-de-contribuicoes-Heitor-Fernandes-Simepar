# Scripts de automação

- `baixar_dados_pc03_azul.py`: baixa o azul/PC03 da SIMEPAR (estação 25354889, sensor 238).
- `atualizar_dados_umidade.py`: atualização coordenada de dados de umidade.
- `executar_analise_conjunta_tres_sensores.py`: executa a análise conjunta histórica.
- `executar_analises_umidade.py`: fluxo histórico do plugfild.
- `executar_analises_umidade_pc03_azul.py`: fluxo histórico do azul/PC03.
- `gerar_csv_sensores_lado_a_lado.py`: gera CSV temporal lado a lado para inspeção.

Antes de rodar scripts históricos, leia seus caminhos de entrada e a data de corte configurada. Para a comparação atual do fim de semana, use `../programas/analise_cs625_pc03_fim_de_semana.R`.
